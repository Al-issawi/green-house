Green House Nablus — Arabic static frontend

Files:
- index.html
- css/style.css



This first version uses only HTML5 and CSS3 (no JavaScript, React, or backend).
The page is Arabic-first and right-to-left. Product cards and contact details are
presentation placeholders until connected to the Spring Boot API and real business data.

Note: Arabic Google Fonts are loaded online. A system sans-serif fallback is included.
